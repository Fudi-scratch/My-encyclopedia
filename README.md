HTML / CSS / JavaScript の用語を自分でまとめていく辞典アプリです。ホーム画面から項目の追加・編集・削除・検索ができます。

**データはブラウザには保存せず、GitHubリポジトリ内のJSONファイル（例：`data/entries.json`）に直接読み書きします。** そのため、同じリポジトリに接続すればどの端末からでも同じ内容を見たり編集したりできます。

## ファイル構成

```
encyclopedia/
├── index.html   画面のHTML
├── style.css    デザイン
└── script.js    追加・編集・検索・GitHubとの通信
```

このアプリ自体は静的なHTML/CSS/JSなので、`data/entries.json` は空でも構いません。初回接続時に見本データが用意され、最初の保存で自動的にファイルが作られます。


## その他の機能

- 項目は **HTML／CSS／JavaScript** の3分類から選んで登録し、ホーム画面上部の分類チップで絞り込めます（索引タブ・検索と組み合わせ可能）。
- 本文では次の簡易記法が使えます。
  - `**太字**`
  - `` `インラインコード` ``
  - `# 見出し`（`#`は1〜3個で大きさが変わります）
  - `- 箇条書き`
  - `` ``` `` で囲んだコードブロック（例：`` ```css `` のように言語名を続けると、その名前がタイトルとして表示されます）
  - `| 列1 | 列2 |` の形式でのテーブル
- 画面下の「GitHubから再読み込み」で、他の端末で加えた変更を取り込めます。
- 「バックアップを書き出す（JSON）」「バックアップを読み込む（JSON）」は、GitHubとは別に手元にもファイルを残したいときの補助機能です。読み込むとその内容がGitHubにも保存されます。

## カスタマイズのヒント

- 初回接続時に表示される9つの見本用語は `script.js` 内の `SEED_ENTRIES` を書き換えることで差し替えられます。
- 配色は `style.css` の先頭にある `:root` 内の変数（`--paper` や `--brass` など）を変えると、全体の印象を変えられます。
